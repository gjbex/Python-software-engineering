# New Type Examples

This directory contains an example illustrating the use of `NewType` to
distinguish values with different semantics.

Type checking can be done using [mypy](http://mypy-lang.org/index.html).


## What is it?

1. `new_types.py`: illustration of using `NewType` to create specific types
   with specific semantics.

Run the checker from this directory with:

```bash
mypy *.py
```
