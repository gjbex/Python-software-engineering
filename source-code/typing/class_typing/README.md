# Class Typing

This directory contains examples illustrating type checking with a
user-defined class.

Type checking can be done using [mypy](http://mypy-lang.org/index.html).


## What is it?

1. `classes.py`: illustration of using type hints with a user-defined class.
1. `classes_incorrect.py`: illustration of using type hints with a
   user-defined class that contains multiple errors.

Run the checker from this directory with:

```bash
mypy *.py
```
