# NumPy Typing

This directory contains an example illustrating type hints for NumPy arrays and
an optional Matplotlib plot.

Type checking can be done using [mypy](http://mypy-lang.org/index.html).


## What is it?

1. `numpy_typing.py`: illustration of a script using both NumPy and Matplotlib
   with type hints.

Run the checker from this directory with:

```bash
mypy *.py
```
